# 清新待办

Windows 桌面待办应用，基于 Electron + React + TypeScript。

- 今天 / 之后两个列表，支持新建、勾选完成、删除（可撤销）。
- 底部输入框可以让 AI 把一段话拆成多条待办，也可以切到「手动添加」直接添加，并选日期和时间。
- 右侧「今日总结」，可重新生成、复制、朗读；每晚自动生成（可关）。
- 系统托盘：最小化时隐藏到托盘（可关），托盘菜单可打开主窗口、开关悬浮窗、退出。
- 悬浮窗：桌面上的小窗口，显示今天的待办，可勾选、直接添加；可置顶、可固定位置和大小。

## 开发运行

```
npm install
npm run dev
```

## 打包

```
npm run dist
```

安装包输出到 `dist\qingxin-todo-setup-<版本>.exe`（NSIS 安装程序，默认当前用户安装，可改安装目录）。
`dist\win-unpacked\` 是未安装的解包目录。第一次打包会下载 electron-builder 需要的工具，需要能访问 GitHub。

## 第一次使用：配置 AI

程序使用 OpenAI 兼容的接口。打开标题栏右侧的「设置」→「AI 服务」：

1. **地址**：填服务商的接口地址，例如 `https://api.deepseek.com/v1`（程序会自动拼上 `/chat/completions`，只允许 http / https）。
2. **模型**：填服务商的模型名。
3. **API Key**：粘贴 Key，点「保存」。保存后界面不再显示 Key，留空表示不修改，「清除」可删除。
4. 点「测试连接」确认能通。Key 框留空时用已保存的 Key，但只在地址和已保存的是同一个站点时才用；
   换了服务商要先填新的 Key 再测试，免得把旧 Key 发给新地址。

Key 使用系统加密（Electron `safeStorage`）保存，settings.json 里只有密文。如果系统加密不可用，程序拒绝保存 Key，不会明文写盘。
换了电脑或系统账户后旧 Key 解不开，设置里会提示「已保存的 Key 无法解密」，重新填一次即可。

**响应速度**：提示词要求模型第一个字就输出 JSON、不写思考过程，总结只让 AI 排最该先做的几件、字数也更短；
提示词末尾的 `/no_think` 会让 Qwen3 这类可开关思考的模型跳过思考，其它模型会忽略它。
DeepSeek-R1 这类纯推理模型的思考过程没法用提示词关掉，想要更快请选非推理模型（例如 `deepseek-chat`）。

## 用法

- 输入框下方可以切换 **AI 整理** / **手动添加**（没配置 AI 时默认手动添加）。
- AI 整理模式：**Enter** 让 AI 把输入内容拆成待办，弹出确认卡片；勾选需要的、修改标题和时间，点「添加」。
  **Ctrl+Enter** 不经过 AI，直接添加。没有配置 AI 时，Enter 也会直接添加，并提示一次。
- 手动添加模式：**Enter** 或「+」按钮直接添加；点输入框右侧的时间胶囊可以选今天 / 明天 / 后天、任意日期和提醒时间。
- 点圆圈勾选完成；鼠标悬停在待办上会出现删除按钮，删除后可以撤销。
- **语音**：麦克风按钮和语音快捷键（默认 `Ctrl + Shift + Space`，可在设置里修改）目前只显示「语音识别还没接入」。语音识别本版未接入。
- 设置里还有每晚自动总结（默认 21:00，可关、可改时间）和开机自动打开。

## 托盘与悬浮窗

- 程序运行时任务栏右下角有托盘图标：单击打开主窗口；右键菜单有「打开清新待办」「悬浮窗」「退出」。
- 「设置」→「窗口」→「最小化到托盘」（默认开）：点最小化时窗口隐藏到托盘，不占任务栏。关闭主窗口仍然是退出程序。
- 悬浮窗：点标题栏「设置」左边的悬浮窗按钮、托盘菜单或设置里的开关打开。悬浮窗标题栏上的按钮：
  - 图钉 = **置顶**（默认开），始终显示在其它窗口上面；
  - 锁 = **固定**，不能拖动、不能改大小，免得误碰；
  - 箭头 = 打开主窗口；× = 关闭悬浮窗。
- 悬浮窗的开关、置顶、固定和位置都会记住，下次启动照原样打开。悬浮窗和主窗口的待办实时同步。

## 数据位置

数据保存在 `%APPDATA%\清新待办\`：

- `tasks.json`：所有待办。
- `settings.json`：AI 地址、模型、加密后的 Key、窗口位置、快捷键、托盘与悬浮窗等设置。

两个文件都可以是 UTF-8 带 BOM（记事本另存的格式也能读）。文件读不懂时，会自动改名备份为 `tasks.corrupt-<时间>.json` 或 `settings.corrupt-<时间>.json`，然后用默认值启动。tasks.json 里个别待办不合法时，只跳过这几条，原文件备份为 `tasks.corrupt-<时间>.json`。备份文件不会被自动删除。

## 挡板模式（测试用）

用环境变量切换，不影响正常使用：

- `QINGXIN_SANDBOX=1`：挡板模式。不注册全局快捷键，开机自动打开只记在设置里、不写入系统，AI 地址只允许 `127.0.0.1`、`localhost`、`[::1]`，不弹系统通知。
- `QINGXIN_DATA_DIR=<绝对路径>`：挡板模式下必填，数据改存到该目录，不碰真实数据。缺少时程序直接退出。
- `QINGXIN_SANDBOX_QUIET=1`：挡板模式下窗口（含悬浮窗）放到所有屏幕之外、不抢焦点、不进任务栏，也不放托盘图标，给自动化验收用。

示例（PowerShell）：

```
$env:QINGXIN_SANDBOX='1'; $env:QINGXIN_DATA_DIR='C:\qx-test\data'; npm run dev
```

挡板只防止程序误用真实数据、真实网络和注册表，不防故意绕过。
